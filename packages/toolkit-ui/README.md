# @ever-teams/toolkit-ui

The base user interface components (buttons, dialogs, inputs, selects, charts, toasts) that the Ever Teams kit's
components are built with. They use Tailwind CSS class names: see the styling step of the
[`@ever-teams/atoms` README](https://github.com/ever-co/ever-teams/tree/develop/packages/toolkit/atoms#readme).

Most hosts install `@ever-teams/atoms` only, which brings this package. MIT licensed.
