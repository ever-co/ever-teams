#Typescript interfaces, Types and Enums

`@ever-teams/toolkit-types` holds the TypeScript interfaces, types and enums shared by the Ever Teams kit packages.
It has no runtime code of its own besides the enums.

Most hosts install [`@ever-teams/atoms`](https://www.npmjs.com/package/@ever-teams/atoms) only, which brings this
package: start with [its README](https://github.com/ever-co/ever-teams/tree/develop/packages/toolkit/atoms#readme).
