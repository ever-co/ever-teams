`timer.watch(listener, { every?, onError? })` on a client of `createClient` tells the listener the timer at a first read, then each start or stop a later read shows, once, wherever it was made. It reads every minute by default (every 15 seconds at the most often), one read at a time, in a page only while it is visible and once more when the page becomes visible or the network comes back, passes a failed read and what the listener throws to `onError` and goes on (without `onError`, a listener's error is thrown again on a fresh task, never as an unhandled rejection), and answers the function that stops it. `timerChangeOf(status, previous)` holds the same rule for a host that reads the status itself. The server entry gets `verifyWebhook({ body, signature, secret, tolerance?, now? })`: it checks the `X-Signature` of a webhook delivery of the API over the raw body (HMAC-SHA256, compared in constant time with the Web Crypto API, so it also runs in a worker or an edge route), refuses a signature more than `tolerance` seconds (300) from now, and answers the event; `isTimeEntryEvent` types the five time entry events (`time_log.started`, `time_log.stopped`, `time_log.created`, `time_log.updated`, `time_log.deleted`). Its refusals are `EverTeamsError` with the codes `WEBHOOK_SIGNATURE`, `WEBHOOK_EXPIRED`, `WEBHOOK_BODY` and `CLIENT_OPTIONS`, each with a next step. Every function exported before works as it did.
